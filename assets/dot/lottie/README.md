# Dot Lottie set

Generated from the supplied `dot-*.svg` artwork as native Lottie vector shapes.

- Canvas: 200 x 200
- Frame rate: 60 fps
- Loop length: 120 frames / 2 seconds
- External image assets: none
- Format: individual Lottie JSON files

## Motion

- `dot-angry`: short controlled shake
- `dot-curious`: subtle tilt / inquisitive lean
- `dot-excited`: bounce with animated excitement rays
- `dot-happy`: soft buoyant idle bounce
- `dot-neutral`: restrained idle motion with blink
- `dot-safety-warning`: pulsing warning badge and warning rays
- `dot-shield`: gently pulsing shield badge
- `dot-surprised`: quick pop/jump with surprise rays
- `dot-thinking`: floating body with sequential thinking dots
- `dot-thumbs-up`: thumb pops in with a small overshoot plus accent rays
- `dot-wink`: calm idle with a tiny wink-line squeeze

The JSON files contain shape layers only; the original SVGs are not embedded as images.
